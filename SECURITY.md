# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 2.0.x | Yes |
| Earlier development builds | No |

## Reporting a vulnerability

Report vulnerabilities privately through the repository's **Security** tab using a private
vulnerability report. Do not open a public issue for an unpatched vulnerability.

Include the affected version or commit, impact, reproduction steps, and any proposed mitigation.
Never include live wallet material, API credentials, or unrelated operator data. The maintainers
will coordinate validation, remediation, disclosure, and credit with the reporter. If the Security
tab is unavailable, contact a Bitcast maintainer through an established private channel and ask for
a secure reporting path without initially sending exploit details.

Operational questions and non-sensitive bugs belong in the normal support path described in
[SUPPORT.md](SUPPORT.md).
