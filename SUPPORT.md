# Support

Use GitHub Issues for reproducible installation problems, operator questions, and non-sensitive
bugs. Search existing issues before opening a new one.

Include:

- the `bitcast-x --version` output and exact commit or image digest;
- whether the affected role is a miner or validator;
- operating-system, Python/Node/PM2, and installation details relevant to the problem;
- redacted logs and the relevant `state-info`, health, or readiness output; and
- minimal reproduction steps and the expected versus observed behavior.

Do not post wallet files, seeds, API keys, authorization headers, private campaign data, or an
unpatched vulnerability. Report security issues privately according to [SECURITY.md](SECURITY.md).

Community support is best-effort and has no guaranteed response time. Production operators remain
responsible for backups, release pinning, monitoring, and rollback readiness.
